# Referencias visuales · Alfa 0.109

Las trece imágenes fueron aportadas por el usuario como objetivo visual para el rediseño. Se conservan en el proyecto para que otro desarrollador pueda comparar cada pantalla. La interfaz se implementa con HTML, CSS y datos reales de la simulación; estas imágenes no se usan como fondos ni sustituyen controles interactivos.

Secuencia: inicio, avisos, ayuda, construir, ciudad, economía, obras, registro, cambios, construir servicios, licitación, pedir materiales y nueva sesión.
